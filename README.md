# MYST 日本語版 Windows 11 対応化パッチ

**保存先を選ぶと、その下に `MYSTJ` フォルダーを自動作成します。別のドライブでも同じ仕組みです。**
例えば `E:\Games` を選ぶと `E:\Games\MYSTJ`、`D:\` を選ぶと `D:\MYSTJ` に導入します。末尾が既に `MYSTJ` の場合は二重作成しません。

MYST 1.0J 日本語版CD-ROMの所有者向けの、非公式の代替インストーラー・専用ランチャーです。現在は **0.1.0-beta.1（試験版）**。
配布ZIPとGitリポジトリには、製品本体・DAT・動画・画像・旧QuickTimeを含めません。
ゲームを動かす際は、元の16ビットEXEを変更する代わりに、公式の **ScummVM** でCDのオリジナルデータを読み込みます。元のEXEを直接動かすパッチではありません。

## 必要なもの

- Windows 11 x64、Python 3.11以降（tkinterを含む通常のWindows版）。
- **MYST 1.0J 日本語版 Windows 3.1向けCD-ROM**。Masterpiece Editionや他の言語・機種版は対象外です。
- 空き容量 約2.2 GB、インターネット接続（公式ScummVM ZIPを約118 MiB取得）。
- このパッチのReleases配布ZIP。自動生成されるSource code ZIPにはランチャーEXEがありません。

## インストール

1. 配布ZIPを展開し、`Install.cmd` を通常権限で起動します。管理者として実行しないでください。
2. 最初の画面の「**MYSTJフォルダーを自動作成する**」案内を確認します。
3. CD-ROMのルート（`MYST.DAT` と `QTW` がある場所）を選びます。ドライブ文字は固定されていません。
4. 保存先を入力するか「参照」で選びます。画面の「実際のインストール先」を確認します。
5. 「この場所にインストール」を押します。CDの版・SHA-256を確認し、データをコピーします。ScummVMは公式サイトから別途取得してSHA-256を検証し、MYSTJ専用の `runtime` に展開します。
6. 完了後、`MYSTJ-Win11.exe` を起動します。CDを取り出しても遊べます。

既存の無関係なフォルダーには上書きしません。1ユーザーにつき1か所をアプリ一覧へ登録します。場所を変える場合は先にアンインストールしてください。導入後にフォルダーを手動移動することには対応していません。

CLIの例（どのドライブでも保存先の下にMYSTJを作成）:

```bat
py -3 mystj.py install --media F:\ --parent E:\Games
```

対応CDを確認するだけなら `--dry-run` を付けます。導入先・レジストリは変更しません。
公式のScummVM ZIPを既に取得している場合は `--runtime-zip "C:\Downloads\scummvm-2026.4.0-win32-x86_64.zip"` を追加すると、ネットからの再取得を省略できます。指定版のSHA-256が一致するZIPだけを使用できます。

## 遊び方と保存先

- `MYSTJ-Win11.exe` で直接ゲームを起動します。ScummVMの一覧に手動登録する必要はありません。
- 初回はウィンドウ表示です。**右クリック** または `Ctrl+F5` でScummVMのゲーム内メニューを開き、保存・ロード・終了します。右クリックのメニュー割り当ては本ツールの初期設定です。
- 設定: `MYSTJ\userdata\scummvm.ini`。
- セーブデータ: `MYSTJ\userdata\saves`。
- スクリーンショットとログも `userdata` に保存します。
- 既存のScummVMの設定ファイルは変更しません。旧QuickTimeや製品の16ビットインストーラーは実行しません。
- 旧版MYSTのセーブファイルをそのまま引き継げることは保証しません。

## アンインストール

1. MYSTJとScummVMを終了します。
2. **設定 → アプリ → インストールされているアプリ → MYST 日本語版（Windows 11対応） → アンインストール** を選びます。
3. 次の方法を選び、最後の確認画面で実行します。キャンセル時は変更しません。

| 方法 | 処理内容 |
| --- | --- |
| 設定・セーブデータを残す（既定） | 本体データ・専用ScummVM・導入ツールとアプリ一覧の登録を削除。`userdata`、追加・変更済みファイルは同じMYSTJフォルダーに残します。 |
| 完全アンインストール | MYSTJフォルダー内の本体・専用実行環境・設定・セーブ・追加ファイルをすべて削除し、アプリ一覧の登録を解除します。保存データは元に戻せません。 |

導入先の `Uninstall.cmd` からも同じ画面を起動できます。他のScummVMインストールや、その設定・セーブには触れません。
「残す」を選んだ後、`userdata` と `retained-data.json` だけが残っている場合は、同じ保存先へ再導入して設定・セーブを引き継げます。それ以外の追加・変更済みファイルが残っている場合は、自分で退避してから再導入してください。

CLIプレビュー（変更なし）:

```bat
py -3 mystj.py uninstall --target E:\Games\MYSTJ --mode keep --dry-run
py -3 mystj.py uninstall --target E:\Games\MYSTJ --mode full --dry-run
```

導入先のパスと製品記録が一致しない場合や、ジャンクション・シンボリックリンクがある場合は停止します。関連アプリを強制終了しません。

## 対応版・確認状況

CD-ROMのハッシュ一覧は `media_manifest.json`。製品データそのものは記録しません。`MYST.DAT` 冒頭5000バイトのMD5は `032c88e3b7e8db4ca475e7b7db9a66bb` で、ScummVMの公式検出テーブルの日本語Windows版と一致します。

2026-10-25にWindows 11 x64日本語環境で、専用ランチャーによる起動・オープニング映像・島への移動・クリック操作・保存ファイルの生成・ロード画面からの自動セーブ選択を確認しました。22件の隔離テストと、CD由来データによる導入・設定保持での削除・再導入・完全削除の通しテストも実施しています。
音声出力・手動セーブ名の入力・ゲーム全編のクリア・全動画と全パズル・別PCでの動作は未確認です。メイキング映像はこのランチャーの対象外です。詳細は `CHANGELOG.md` を参照してください。
不具合報告にはWindowsの版、CDの版、エラーを記載し、製品データやCDイメージは添付しないでください。
